# Django Admin и учётные записи

## Чем Django Admin отличается от ролей сайта

Панель Django `/admin/` — инструмент обслуживания данных проекта. Для входа нужны права Django `is_staff`; суперпользователь имеет их автоматически. Поле «Роль» (`Клиент`, `Курьер`, `Менеджер`, `Администратор`) управляет возможностями внутри сайта и само по себе не даёт доступ к `/admin/`.

Самостоятельная регистрация на сайте всегда создаёт клиента. Менеджерам и курьерам аккаунты выдаёт администратор.

## Создать первого администратора

В PowerShell из корня проекта выполните:

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

Введите логин, почту и пароль в ответ на запросы команды. Запустите проект (`runserver`), откройте `http://127.0.0.1:8000/admin/` и войдите созданным аккаунтом.

Для удобной навигации по самому сайту откройте в Django Admin раздел **Users / Пользователи**, найдите суперпользователя, установите роль **Администратор** и сохраните. Флаг суперпользователя уже даёт полный доступ к Django Admin; роль сайта добавляет доступ к панели заказов и отчётам.

> Выдавайте суперпользователя только человеку, которому можно доверить все данные и настройки проекта. Для обычной работы менеджеру полный доступ к Django Admin не нужен.

## Создать клиента, менеджера или курьера

В Django Admin откройте **Users / Пользователи → Add / Добавить**:

1. Задайте уникальный логин и пароль, сохраните новую запись.
2. Откройте созданного пользователя и заполните уникальную электронную почту.
3. Выберите роль, проверьте **Active / Активен** и сохраните.

Примеры настройки:

- **Клиент:** роль «Клиент». Обычному клиенту проще зарегистрироваться самостоятельно через `/accounts/register/`; роль клиента назначается автоматически.
- **Менеджер:** роль «Менеджер». Оставьте `Staff status` выключенным, если этому человеку не нужен Django Admin. Панель менеджера доступна по `/orders/manager/`.
- **Курьер:** роль «Курьер», затем обязательно создайте ему профиль курьера (следующий раздел).
- **Администратор:** роль «Администратор» открывает рабочие панели сайта, но для `/admin/` дополнительно нужен `Staff status` и разрешения Django. Для главного локального администратора используйте `createsuperuser`.

Пользователь может входить по почте или логину. Не создавайте один общий аккаунт на нескольких сотрудников: автор действий записывается в историю статусов заказа.

## Подключить курьера

После создания пользователя с ролью «Курьер»:

1. В Django Admin откройте **Courier profiles / Профили курьеров → Add**.
2. Выберите пользователя-курьера.
3. Оставьте **Available / Доступен** включённым, задайте зону при необходимости и лимит активных доставок (по умолчанию 3).
4. Сохраните профиль.

Менеджер увидит только активных, доступных курьеров с профилем. Если курьер временно не принимает заказы, выключите **Available**. Для полного запрета входа снимите **Active** у пользователя.

## Что можно обслуживать в панели

- **Restaurants:** создавать и редактировать рестораны, расписание доставки и видимость.
- **Categories:** создавать категории меню; отключённые категории не показываются клиентам.
- **Products:** привязать блюдо к ресторану и категории, указать цену и остаток; выключенные или закончившиеся блюда нельзя заказать. Загружаемое изображение должно быть JPEG, PNG или WEBP не больше 5 МБ.
- **Users / Addresses:** управлять аккаунтами, ролями и сохранёнными адресами.
- **Courier profiles:** настраивать доступность и лимит курьеров.
- **Carts:** просматривать корзины.
- **Notifications:** просматривать уведомления.
- **Orders, Order status history, Deliveries, Reviews:** смотреть записи и историю.

Статус заказа и назначения курьеров нельзя менять в Django Admin: это сделано, чтобы не пропускать проверки остатков, ролей и истории изменений. Используйте рабочие панели из [инструкции менеджера и курьера](staff.md).
