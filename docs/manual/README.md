# Руководство по проекту «Везём»

Здесь собраны инструкции для клиента, менеджера, курьера и администратора.

## Разделы

- [Работа клиента](client.md): регистрация, профиль, заказ, статусы и отзыв.
- [Django Admin](admin.md): вход, создание пользователей и обслуживание каталога.
- [Менеджер и курьер](staff.md): обработка заказа от подтверждения до доставки.

## Быстрый запуск на Windows

Команды выполняются из папки проекта в PowerShell. Если виртуальное окружение и зависимости уже настроены, переходите сразу к миграциям и запуску.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_restaurants
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

Откройте сайт по адресу `http://127.0.0.1:8000/`. Панель Django находится по адресу `http://127.0.0.1:8000/admin/`.

Если файла `.env` ещё нет, создайте его из `.env.example`. Пустой `DB_NAME` включает локальную SQLite. Не перезаписывайте уже настроенный `.env` и не публикуйте его: там могут быть пароли базы и секретный ключ.

`seed_restaurants` создаёт демонстрационные рестораны и блюда. Команду можно запускать повторно. Для внешних фотографий блюд требуется интернет.

## Роли и страницы

| Роль | Для чего нужна | Страница |
| --- | --- | --- |
| Клиент | Корзина, оформление и собственные заказы | `/accounts/profile/`, `/orders/history/` |
| Менеджер | Подтверждение заказов, сборка и назначение курьеров | `/orders/manager/` |
| Курьер | Работа только с назначенными доставками | `/delivery/courier/` |
| Администратор сайта | Доступ к рабочим отчётам и панели управления Django при наличии `is_staff` | `/analytics/`, `/admin/` |

У каждой роли может быть свой логин. Самостоятельная регистрация на сайте создаёт только клиента. Не выдавайте клиентским аккаунтам права менеджера или администратора.

## Основной путь заказа

1. Клиент регистрируется, указывает имя, телефон и адрес, выбирает ресторан и оформляет корзину.
2. Новый заказ получает статус «Ожидает подтверждения».
3. Менеджер подтверждает заказ и переводит его в сборку.
4. Менеджер назначает доступного курьера. После назначения статус меняется на «Назначен курьер».
5. Курьер обновляет этапы доставки в своём кабинете.
6. Клиент смотрит историю статусов и уведомления; после доставки может оставить отзыв.

Для учебной версии оплата демонстрационная: деньги по карте проект не списывает.
